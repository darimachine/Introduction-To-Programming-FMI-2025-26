## 🚀 Какво е Git?

**Git** е система за контрол на версиите (**Version Control System**), която ни позволява да следим промените по даден проект и да работим по-лесно в екип.

С Git можете да:

- 📜 Следите историята на промените по проекта
- 💾 Запазвате различни версии на кода
- 🌿 Работите по нови функционалности чрез отделни branch-ове
- 👥 Работите едновременно с други разработчици
- 🔄 Синхронизирате локалния си проект с GitHub
- ⏪ Връщате проекта към предишна версия, ако нещо се обърка

---

## 🐙 Какво е GitHub?

**GitHub** е платформа, в която могат да се съхраняват Git repositories и да се разработват проекти съвместно с други хора.

Най-просто казано:

**Git** → инструментът, с който управляваме версиите на проекта.

**GitHub** → мястото, където можем да съхраняваме и споделяме Git проектите си.

## 🧰 Основни Git команди

Ето някои от най-често използваните команди:

- `git clone <repository-url>`  
  Изтегля съществуващо repository на вашия компютър.

- `git status`  
  Показва текущото състояние на repository-то и кои файлове са променени.

- `git add <file>`  
  Добавя конкретен файл към **staging area**.

- `git add .`  
  Добавя всички текущи промени към **staging area**.

- `git commit -m "message"`  
  Запазва добавените промени като нов commit.

- `git pull`  
  Изтегля последните промени от remote repository-то.

- `git push`  
  Качва вашите локални commits в remote repository-то.

- `git branch`  
  Показва наличните локални branch-ове.

- `git switch <branch-name>`  
  Преминава към друг branch.

- `git switch -c <branch-name>`  
  Създава нов branch и преминава към него.

## 🔄 Основен Git workflow

В повечето случаи работният процес изглежда приблизително така:

```bash
# Изтегляме последните промени
git pull

# Проверяваме текущото състояние
git status

# Правим необходимите промени...

# Добавяме промените
git add .

# Създаваме commit
git commit -m "Добавяне на моите промени"

# Качваме промените
git push
```

Накратко:

### `Pull → Промени → Add → Commit → Push` 🚀

---

## 🌿 Работа с branch

Когато работите по нова задача или функционалност, е добра практика да създадете отделен branch.

Например:

```bash
git switch -c my-feature

# Правим необходимите промени...

git add .

git commit -m "Add my feature"

git push -u origin my-feature
```

По този начин вашите промени са отделени от основния branch на проекта.

## 💡 Няколко полезни съвета

- 🔍 Използвайте `git status`, когато не сте сигурни какво се случва.
- ⬇️ Правете `git pull`, преди да започнете работа.
- ✍️ Пишете кратки и ясни commit съобщения.
- 📦 Не слагайте много несвързани промени в един commit.
- 🌿 Използвайте отделни branch-ове за различни задачи.
- ⚠️ Не използвайте Git команди, които не разбирате, само защото сте ги намерили в интернет.
- 🧪 Не се притеснявайте да експериментирате — това е един от най-добрите начини да научите Git.
